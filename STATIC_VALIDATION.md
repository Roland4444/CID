# Статическая валидация проекта v0.5

Статическая проверка структуры и ссылок на конфигурацию выполнена. В исходном коде присутствует прямой клиент DSM HTTPS (`src/synology.rs`), в сервисе присутствует клиент и состояние последней успешной проверки, в БД — `synology_file_index`. Все скрипты миграций поставляются в архиве.

**Ограничение:** доступный контейнер не содержит компилятора Rust (`cargo`, `rustc`) и не предоставляет живой экземпляр DSM/PostgreSQL. Статическая проверка не является доказательством компиляции, правильной работы HTTPS-авторизации или эксплуатационной готовности. Инструкция для реальной проверки — `INSTALL_UBUNTU_RU.md`.
