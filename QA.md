# Проверки и ограничения v0.5

## Выполнено при формировании исходников

- Проверено наличие всех 12 модулей Rust, `Cargo.toml`, SQL-миграций `001`–`004` и справочников.
- Проверено, что старая логика SMB `WATCH_ROOT`, `REQUIRE_MOUNT`, `mountpoint` удалена из Rust-кода.
- Проверено, что сетевой модуль Synology вызывает только `SYNO.API.Auth`, `SYNO.FileStation.List`, `SYNO.FileStation.Download`, а не методы записи/удаления.
- Проверено, что в примере конфигурации отдельно заданы `DATABASE_URL`, `SYNOLOGY_URL`, `SYNOLOGY_ROOT` и `SYNOLOGY_VERIFY_TLS`.
- Проверены данные каталогов из исходного ТЗ: 14 видов работ, 169 обязательных/условных позиций, 34 ошибки.
- Проверено наличие инструкции Ubuntu с командами PostgreSQL, сборки, systemd и диагностики.

## НЕ выполнено в доступном окружении

- Нет установленного `cargo` / `rustc`: не выполнялись `cargo check`, `cargo test`, `cargo build`.
- Нет реального доступа к DSM, поэтому не проверены авторизация на конкретной версии DSM, API Info discovery, list, download.
- Нет настроенной пользовательской PostgreSQL: SQL-миграции не прогонялись на живой БД.
- Не проводилось нагрузочное тестирование PDF/OCR, контроль ролей/безопасности и промышленное приёмочное испытание ГОСТ.

## Команды в среде Ubuntu после развёртывания

```bash
cargo fmt --all -- --check
cargo check
cargo test
cargo build --release
./target/release/id-control-axum --check-synology
sudo systemctl enable --now id-control-axum
sudo journalctl -u id-control-axum -n 100 --no-pager
curl -u admin http://127.0.0.1:8090/health
```

Для проверки возьмите специально созданные тестовые комплекты: корректный набор, пропущенный обязательный документ, изменённую версию файла, испорченный DOCX, скан PDF, недоступную NAS и неверную папку. Важное условие: после недоступности NAS ранее сохранённые документы не должны массово помечаться как отсутствующие.
