# Качество / проверка версии 0.4

## Что проверено при подготовке

- ZIP исходной версии раскрыт успешно, версия 0.3 собрана из его файлов.
- JSON каталога валиден: 14 видов работ, 169 позиций, 34 типовые ошибки.
- Исключено обращение к LanguageTool и автоматическое исправление DOCX.
- Добавлены нормативные правила с явным утверждением, таблица результатов проверок и идемпотентная миграция 002.
- В модуле `norms.rs` предусмотрены тесты нормализации, обнаружения формальных пропусков, недостоверности OCR, запрета неутверждённых правил и обязательной ручной проверки.

**Не проверено в этом окружении:** Rust toolchain отсутствует (`cargo`, `rustc`); поэтому проект не прошёл компиляцию и `cargo test`. PostgreSQL, файловая система Synology и приложение здесь не запускались. Настоящую строительную нормативную базу необходимо загрузить и утвердить перед проверками.

## Перед применением в компании

```bash
cargo fmt --all
cargo fmt --all -- --check
cargo check
cargo test
cargo build --release
```

После запуска на тестовой базе убедитесь, что:

1. Пустая база нормативных правил приводит к `N-RULES-NONE`, а не «соответствует».
2. Неутверждённые нормативные правила не запускаются.
3. Утверждённое правило с известными ссылкой, пунктом и редакцией регистрирует `normative_check_results`.
4. Неточный OCR и текст из сканированного PDF получают `manual`.
5. Для DOCX с нарушением текстового правила появляется предварительное замечание со ссылкой на норму.
6. После отзыва правила оно перестаёт применяться в будущих проверках, история старых результатов сохраняется.
7. Доступ к NAS только на чтение, при временном отключении NAS нет ложного массового удаления.
8. Экспорт формирует четыре обязательные колонки без автоматического объявления о полном соответствии ГОСТам.
9. Запуск через `systemd` работает под отдельным пользователем, HTTP-сервер слушает только localhost и публикуется исключительно через внутренний HTTPS reverse proxy/VPN.

**Предупреждение:** `migrations/001_init.sql` создаёт таблицы без разрушительных операций. Сохраните резервную копию базы перед обновлением с 0.2 на 0.3.


## Дополнительные проверки v0.4

- Добавлены тесты `docs.rs`: фрагменты `w:t` склеиваются без искусственных пробелов, в том числе при разных стилях Word.
- Добавлены тесты `norms.rs`: утверждённый регулярный шаблон и обработка некорректного регулярного выражения.
- Проверка `/health`: количество утверждённых правил рассчитывается запросом SQL, а не фиксированной константой.
- Применяется миграция `003_norm_patterns.sql` для расширенного ограничения `check_kind`.

**Указанные модульные тесты добавлены в код, но не выполнялись:** компилятор Rust в окружении разработки отсутствует.
